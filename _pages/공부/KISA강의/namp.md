# Nmap
----------------------------------



##  IP·포트 정보 수집: Nmap

- IP 범위와 서비스 포트 수집은 부차적으로 보일 수 있지만, 실제로 **포트 스캐닝만으로 버그바운티에 성공한 사례**가 존재함
- 포트 스캐닝은 대상 서비스에서 어떤 서비스가 동작 중인지 확인하는 좋은 수단이자 또 다른 정보 수집 전략임
- **Nmap(Network Mapper)**: 네트워크 보안 감사와 탐사를 위해 개발된 오픈소스 스캔 도구
  - 서버·네트워크 장비의 인터페이스와 개방 여부를 확인
  - 서비스가 동작 중인 포트, 사용 중인 프로토콜, OS 정보 등을 제공해 취약점 파악에 필수적인 데이터를 제공함

주요 옵션

```bash
nmap -p22 <target>      # 특정 포트(22번)만 스캔
nmap -sV <target>       # 서비스 버전 정보 확인
nmap -O <target>        # 대상 호스트의 운영체제 판별
nmap -v <target>        # 스캔 과정을 상세하게 출력(verbose)
```

### Nmap 스크립트 엔진(NSE)

- NSE(Nmap Scripting Engine)는 네트워크 스캔을 자동화하는 강력한 기능
- 사용자가 직접 스크립트를 작성하거나, 기본 제공되는 수백 개의 스크립트를 활용할 수 있음
- 네트워크 탐색, 정보 수집, 취약점 감지 등 다양한 작업에 활용 가능


```bash
nmap -sC <target>                 # 기본 제공 스크립트로 스캔
nmap --script <script-name> <target>   # 특정 스크립트 지정 스캔 (많은 데이터를 수집하며 대상에 부하를 줄 수 있어 주의 필요)
```
